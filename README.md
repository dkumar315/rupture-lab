# RuptureLab

RuptureLab is an API resilience testing workbench for deliberately introducing controlled failures and measuring whether an application recovers correctly.

The project is currently under active development.

## What it will test

RuptureLab will support repeatable experiments involving:

- HTTP failures
- artificial latency
- request timeouts
- malformed responses
- rate limiting
- recovery behaviour

Experiments will compare normal operation, degraded operation and recovery against explicit resilience contracts.

## Planned stack
